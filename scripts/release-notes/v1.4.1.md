# OmniAPI v1.4.1

小版本：**覆蓋安裝新版之後，「開機時啟動」不會再被清掉**；費用帳補上之前記成空白的幾種生成（標「估」）；幾個 1.4.0 留下的小問題修掉，設定頁與聊天的模型清單也有了篩選列。

## 修正

- **開機時啟動撐過覆蓋安裝**：以前直接執行新版安裝包覆蓋安裝，會把「開機時啟動」默默關掉（安裝程式升級時先跑舊版的解除安裝，它會刪掉開機啟動的登錄值）。現在桌面版把你的選擇記在資料夾裡（`autostart.pref`），安裝程式裝完照它寫回去、桌面版啟動時也會檢查並補回。**從 1.4.0 升到 1.4.1 這一次例外**：1.4.0 還沒記這個選擇，裝完請從系統匣或設定頁再勾一次，之後的升級就會保住
- **沒有回報用量的費用改記預估、標「估」**：ElevenLabs 的語音以前帳上是空的（ElevenLabs 不回報用量），現在照字數與單價記；OpenAI tts-1、帶得到音檔長度的轉錄、有給長度的 ElevenLabs 音樂也一樣。直連 OpenAI 與 Gemini 的生圖本來就是照品質與尺寸估的，現在照實標出來。費用頁、作品詳情、生成頁的出件口與聊天的提議卡，金額旁都會標「估」，合計含預估的也會標。舊紀錄不會補標
- 生成頁影片清單底下「另有 N 個不是生影片的」那句，螢幕閱讀器讀得到數字了；模型清單每一列的無障礙名稱都是模型名
- 作品詳情的「首幀」「尾幀」那一列可以點，跳到來源那件作品
- Suno「延長上傳的歌」：帶提示詞、風格、標題與接續秒數的自訂模式改走 kie.ai 的新端點（用真的 key 試過，成功）；只給音檔的模式在新端點仍會失敗，繼續走舊端點
- 一支偶發失敗的測試修掉了（影片工作在帳記好之前就顯示結束的時間差）

## 新東西

- 設定頁的模型挑選器、聊天裡「換生成模型」的小視窗，也有跟其他地方一樣的篩選列（搜尋、照熱門／廠商／價格排、廠商與能力篩選）；清單短的時候不出現
- 設定頁〈音樂〉多一個「音樂收幾首」：Suno 一次做出兩首，可以改成只收第一首（以前只能改設定檔）
- 給 Claude Desktop 的擴充（`omniapi-mcp.dxt`）多了選填的 Google、Anthropic、DeepSeek key 欄位
- MCP 的 `list_available_models` 說明寫清楚了 `rank` 是什麼（Artificial Analysis 排行榜名次，越小越熱門；沒有名次就沒有這一欄）

## 下載

| 檔案 | 用途 |
|---|---|
| `OmniAPI_1.4.1_x64-setup.exe` | **桌面版安裝包**。下載後執行；已經裝了舊版就直接覆蓋安裝 |
| `omniapi-v1.4.1.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |
| `omniapi-mcp.dxt` | Claude Desktop 擴充。獨立的 stdio 版 MCP server，沒有網頁介面 |
| `omniapi-skill.zip` | 給 Claude 讀的 skill，放進 `~/.claude/skills/` 或上傳到 claude.ai |
| `SHA256SUMS.txt` | 上面四個檔的 SHA-256 |

**安裝包沒有程式碼簽章**，第一次執行時 Windows 可能會顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。想確認檔案沒被動過，用 `Get-FileHash OmniAPI_1.4.1_x64-setup.exe` 對 `SHA256SUMS.txt`。

## 升級

- **桌面版**：直接執行新的安裝包覆蓋安裝。設定、key、資料庫與作品都不會動。裝完從開始功能表或系統匣重新打開，**再勾一次「開機時啟動」**（只有這一次）
- **zip**：換上新版後在 `mcp/` 執行一次 `uv sync`，再重啟服務（`uv run omni stop` 再 `uv run omni serve`）
- 資料庫會在第一次啟動時自動加上「是不是預估」的欄位，舊的紀錄不變

## 測過什麼、沒測過什麼

測過（都在一台 Windows 11 上）：

- 全部單元測試；聊天、生成、作品、設定、OpenRouter 圖片、影片的端到端測試，都在不連外的測試環境
- 開機啟動：用另一個名字的測試版安裝包，在暫存資料夾裝舊版、開啟開機啟動、照安裝程式「已安裝」頁的做法覆蓋安裝新版——裝完還沒打開程式時登錄值就在；刪掉登錄值再打開程式，會補回來；關掉的開機啟動升級後維持關閉。也重現了舊版會把它清掉的情況當對照
- 用 1.4.0 格式的資料庫升級，舊紀錄都標成「不是預估」
- 畫面在寬版與手機寬度逐頁截圖檢查（新的篩選列、音樂設定、「估」、首幀連結）
- Suno「延長上傳的歌」兩種模式各用真的 key 送過一次

**沒測過**：

- 正式安裝包從 1.4.0 覆蓋安裝在真的環境裡（發布前由作者自己裝一次）；開機啟動的測試是在測試版上做的，沒有實際登出再登入
- 「估」的金額沒有用真的 key 生一段 ElevenLabs 語音對過（照目錄單價與字數算）
- 沒有在另一台乾淨的電腦上實機安裝過

## 已知限制

- 從 1.4.0 升級這一次，開機啟動要自己再勾一次（見上面〈修正〉）
- 真的解除安裝之後再裝回來，開機啟動會跟著回來（你的選擇留在資料夾裡，跟其他設定一樣）；不想要就在解除安裝前先關掉
- Gemini TTS、gpt-4o-mini-tts 等照 token 計價的語音，以及聊天，費用照供應商回報的用量記，不標「估」；沒有回報用量的就照舊記成未計價
- 其餘同 v1.4.0：影片沒有真的取消；按 token 計價的影片模型送出前算不出金額；只在 Windows 11 上測試過；不要把 7788 埠開放到網路上；預估費用是估算，實際以供應商帳單為準
