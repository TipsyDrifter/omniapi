# OmniAPI v1.2.0

聊天升級：可以貼圖、丟檔案、在對話裡生成圖片與語音，回覆可以重來、舊訊息可以改。

## 新東西

- **聊天附件**
  - 圖片：貼上、拖進、從電腦選，或從作品牆挑；一則最多 10 個附件，只有附件沒有字也能送
  - 檔案：什麼檔都收得下（50 MB 內）。文字類、PDF、Word、Excel、PowerPoint 會在你的電腦上抽出文字；模型原生看得懂的（例如 PDF 給 Claude 與 GPT）原樣送出，看得到版面
  - 太長的檔案只送開頭，模型會自己用工具讀需要的段落；回覆上方看得到它讀了哪裡
  - 每則回覆都標明每個檔案是怎麼送的（原樣、抽出文字、只送一部分、讀不了與原因）
  - 錄音：聽得到音訊的模型直接聽；聽不到的，回覆前先問你要不要轉成文字（會顯示預估費用），轉好自動接著回答
  - 不會看圖的模型，附圖會反灰並說明；讀不了的檔案照實說，不假裝看過
- **在對話裡生成圖片與語音**
  - 跟模型說「幫我畫…」「把這段唸出來」，它會在對話裡放一張提議卡：提示詞、建議的生成模型、預估費用
  - **你按下「生成」才會生成、才會計費**；可以先改提示詞或換模型，也可以按「不用了」（之後還能重新打開）
  - 做好的作品直接出現在對話裡，同時進作品牆（來源標「聊天」）
  - 不會用工具的模型不能在對話裡生成，輸入框旁會標明
- **重新生成與分岔**
  - 任何一則回覆都能重新生成，用的是輸入框上方「下一則用」的模型——換個模型重答同一題很方便
  - 自己的舊訊息可以編輯後重送，從那裡分出新的一條；原本的對話留著
  - 用 ‹ 2/3 › 在版本之間切換
- **刪除聊天**：真的刪掉、無法復原；這段聊天生成的作品仍在作品牆，費用仍在帳上。只是不想看到它的話，用封存
- **送出鍵設定**：可以選「Enter 直接送出（Shift+Enter 換行）」或維持 Ctrl+Enter；聊天、追問、派工、生成頁一起生效。輸入法選字時的 Enter 不會送出

## 修正與調整

- 上傳的回應不再包含檔案在電腦上的路徑
- 聊天清單：回覆很快時，新聊天不會再一直顯示「（未命名）」
- 聊天上傳的一般檔案一律以下載方式提供，不會在瀏覽器裡被當成網頁打開

## 下載

| 檔案 | 用途 |
|---|---|
| `omniapi-v1.2.0.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |
| `omniapi-mcp.dxt` | Claude Desktop 擴充。獨立的 stdio 版 MCP server，沒有網頁介面 |
| `omniapi-skill.zip` | 給 Claude 讀的 skill，放進 `~/.claude/skills/` 或上傳到 claude.ai |

## 從 v1.1.0 升級

- 換上新版後在 `mcp/` 執行一次 `uv sync`（這一版多了讀 PDF 與 Office 文件的套件），再重啟服務（`uv run omni stop` 再 `uv run omni serve`）
- 資料庫會自動升級：既有的聊天內容與順序不變。**升級後不要再用 v1.1.0 開同一份資料**（舊版不認得分岔，新寫入的訊息會接不上）
- 已經開著的 Claude Code 要重新連線一次 MCP
- OpenRouter 的模型要等模型清單重新整理後（24 小時內自動，或手動重新整理），才認得出哪些會用工具、收檔案與音訊

## 注意

- 只在 Windows 11 上測試過
- 發布前以真模型測過的：OpenAI、Google Gemini、DeepSeek、OpenRouter 的看圖、對話裡生成、檔案與錄音。**Anthropic 直連（Claude 的看圖、PDF、開著思考時的工具呼叫）依官方文件實作，這一版發布時尚未以付費帳號實測**；經 OpenRouter 使用 Claude 不受影響
- Gemini 目前收到的 PDF 是抽出的文字（看不到版面與圖表）；錄音可以直接聽
- 附件會送給你選的模型供應商；抽文字在你的電腦上做，不經過第三方
- 生成、轉錄會用你自己的 API key 呼叫供應商並產生費用；預估費用是估算，實際以供應商帳單為準
- 模型讀很長的檔案時會多呼叫幾次模型，費用合併記在同一則回覆
- 還不支援：讓模型寫程式分析檔案、聊天裡生成音樂、影片
- 服務沒有登入機制，只綁本機；不要把 7788 埠開放到網路上
