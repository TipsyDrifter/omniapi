# OmniAPI v1.1.0

圖片、語音、音樂、轉錄進了網頁介面：不開 Claude Code 也能生成，做出來的東西都收在一面作品牆。

## 新東西

- **生成頁**（導覽「生成」）：四種表單——圖片（生圖；放一張來源圖就是改圖）、語音（選聲音、可試聽、做好當場播）、音樂（照描述或照歌詞）、轉錄（上傳音檔或從作品裡挑）
  - 送出前顯示**預估費用**與算法；按 token 計價的圖片模型用你過去同樣設定的實際花費來估
  - 不能用的模型會反灰並說明缺什麼
  - 生成在服務裡背景跑：音樂要等幾分鐘，離開頁面再回來它還在；可以中止
  - 失敗會說原因（額度、金鑰、內容被擋、逾時…），可以再試一次或帶回表單修改
- **作品牆**（導覽「作品」）：所有入口做出來的圖、語音、音樂、歌詞、逐字稿都在這裡
  - 依種類、來源、模型、日期篩選，搜尋提示詞、內文與檔名
  - 詳情頁有完整提示詞、設定、費用，以及來源與衍生作品；可以下載、拿去改圖、拿去轉錄、用同樣設定再生一次
  - 別處剛做好的作品會即時出現
  - 「從牆上移除」只是隱藏，不會刪檔
  - 升級後第一次啟動會把作品資料夾裡既有的檔案登記進來
- **逐字稿會存檔**：以前轉錄結果只在回覆裡，現在全文存成檔並進作品牆
- **Google Lyria 音樂**：`lyria-3.5`、`lyria-3-clip-preview`（需要 Gemini API 的付費層）
- **Gemini 語音可輸出 MP3**：電腦上有 `ffmpeg` 時自動轉檔，沒有則維持 WAV
- **語音的聲音清單**：OpenAI 13 個、Gemini 30 個內建聲音；ElevenLabs 列出你帳號裡的聲音
- **費用頁**多了「最近的生成」，每一筆連到它的作品
- **終端機**：`omni works` 列出、搜尋作品
- 看板活動流裡 agent 說的話以 markdown 呈現；網頁首屏的檔案變小

## 修正

- 超過 45 秒的生成（會先回取件單的那種），費用現在記在送出的那一筆帳上；以前沒有回來領結果就不會入帳
- Gemini 的思考 token 計入費用；DeepSeek 尖峰時段的價格
- 被迫走 Claude Code 的 OpenAI／Google 模型改由 OpenRouter 送出並正確記錄

## 下載

| 檔案 | 用途 |
|---|---|
| `omniapi-v1.1.0.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |
| `omniapi-mcp.dxt` | Claude Desktop 擴充。獨立的 stdio 版 MCP server，沒有網頁介面 |
| `omniapi-skill.zip` | 給 Claude 讀的 skill，放進 `~/.claude/skills/` 或上傳到 claude.ai |

## 從 v1.0.0 升級

- 換上新版後重啟服務（`uv run omni stop` 再 `uv run omni serve`）。資料庫會自動加上新的表，既有資料不動
- 已經開著的 Claude Code 要重新連線一次 MCP
- skill 有更新，重新放一次 `skill/omniapi/`

## 注意

- 只在 Windows 11 上測試過
- 生成會用你自己的 API key 呼叫供應商，會產生費用；預估費用是估算，實際以供應商帳單為準
- Google 的生圖與 Lyria 需要在 AI Studio 開啟帳單；Lyria 的接線依官方文件實作，這一版發布時尚未以付費帳號實測
- 服務沒有登入機制，只綁本機；不要把 7788 埠開放到網路上
- 還不支援影片
