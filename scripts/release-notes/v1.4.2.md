# OmniAPI v1.4.2

小版本：**用 Claude 模型時帶 `thinking` 不會再被拒（HTTP 400）**；網頁聊天裡的模型不會再稱你「主人」；MCP 工具的說明改成照程式實際的行為寫，給 Claude 讀的 skill 也一起更新。

## 修正

- **`complete_text` 的 `thinking` 對 Claude 不會再 400**：`thinking` 原本是 DeepSeek 的開關，傳給 Claude 時會原樣送出，Claude Opus 5.5、Fable 5.1 等新模型兩種值都會拒絕。現在 `thinking=true` 會換成 Claude 收的「自適應思考」（有給 `reasoning_effort` 就照它的深度，沒給就用模型自己的預設）；`thinking=false` 在一律會思考、關不掉的模型上會被拿掉並在結果裡留一句說明。對 Claude 還是建議直接用 `reasoning_effort`
- **聊天模型對你的稱呼**：網頁聊天告訴模型的幾段話（提議生圖或配音的工具、提議的結果、聽不到的錄音）以前稱你「主人」，模型會跟著這樣叫；現在一律是「使用者」。派工權限頁「用主人的 Claude 訂閱額度」也改成「用你的」

## MCP 工具的說明

這些是 Claude 等模型呼叫 OmniAPI 時讀到的說明文字，功能本身沒變：

- `generate_video`：`max_cost_usd` 寫清楚是「你同意的金額」，模型要先問過你才帶上，不能自己加上去放行
- `generate_music`：補上 Google Lyria（`lyria-3.5`、`lyria-3-clip-preview`）；ElevenLabs 的預設是 `music_v2_5`
- `generate_speech`：補上 ElevenLabs `eleven_v4`、`eleven_v4_turbo`；OpenAI `tts-1`／`tts-1-hd` 標明 2027-01-06 關閉；Gemini TTS 在有 ffmpeg 時給 MP3
- `generate_image`／`edit_image`：gpt-image-2 的自訂尺寸規則、透明背景只在哪幾個模型有效、`style` 已沒有模型使用；改圖怎麼依模型分流、遮罩只有 OpenAI 吃（透明處＝要重畫）
- `health_check`、`server_info`：照實寫檢查了什麼（`health_check` 只檢查生圖的供應商）
- `run_agent`、`cancel_run`：派出去的 agent 會真的改檔、會花錢；沒給 `cwd` 時在哪裡跑；中止後已做的修改不會還原
- `list_available_models`：說明回傳的 `tiers`、`configured_providers`、`image_params`、`video_params` 等欄位

## 移除

- MCP 的 `models://list`、`model-info://{model_id}` 兩個 resource：讀的是很久以前的靜態資料（含已下架的模型），會跟即時名單打架。要看模型請用 `list_available_models`

## skill

- `omniapi-skill.zip` 更新：遮罩的說明、音樂預設模型、Gemini TTS 格式、`health_check` 的範圍等修正；界線一節只寫 OmniAPI 做什麼、不做什麼

## 下載

| 檔案 | 用途 |
|---|---|
| `OmniAPI_1.4.2_x64-setup.exe` | **桌面版安裝包**。下載後執行；已經裝了舊版就直接覆蓋安裝 |
| `omniapi-v1.4.2.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |
| `omniapi-mcp.dxt` | Claude Desktop 擴充。獨立的 stdio 版 MCP server，沒有網頁介面 |
| `omniapi-skill.zip` | 給 Claude 讀的 skill，放進 `~/.claude/skills/` 或上傳到 claude.ai |
| `SHA256SUMS.txt` | 上面四個檔的 SHA-256 |

**安裝包沒有程式碼簽章**，第一次執行時 Windows 可能會顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。想確認檔案沒被動過，用 `Get-FileHash OmniAPI_1.4.2_x64-setup.exe` 對 `SHA256SUMS.txt`。

## 升級

- **桌面版**：直接執行新的安裝包覆蓋安裝。設定、key、資料庫、作品與「開機時啟動」都不會動
- **zip**：換上新版後在 `mcp/` 執行一次 `uv sync`，再重啟服務（`uv run omni stop` 再 `uv run omni serve`）
- 用到 `models://list` 或 `model-info://` 的 MCP client 改用 `list_available_models`

## 測過什麼、沒測過什麼

測過（都在一台 Windows 11 上）：

- 全部單元與整合測試，含新加的 `thinking` 對 Claude 的測試（送出的請求內容，不連外）
- zip 從零安裝後在不連外的測試環境跑安裝驗證
- 用另一個名字的測試版安裝包，在暫存資料夾裝、啟動、覆蓋安裝

**沒測過**：

- `thinking` 沒有用真的 Anthropic key 打過 Claude（照 Anthropic 文件的參數規則與請求內容的測試）
- 沒有在另一台乾淨的電腦上實機安裝過
