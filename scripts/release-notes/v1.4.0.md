# OmniAPI v1.4.0

影片來了：在生成頁或從 Claude Code 叫一支影片，等得住、算得清楚。圖片多了一大批模型（FLUX、Seedream、Grok Imagine、Qwen、Recraft、MAI……）。**不用另外辦 key**：這些都走你現有的 OpenRouter key；有 Google 的 key（開了 Gemini API 付費層）還可以直連 Google 的 Gemini Omni 生影片。挑模型的清單也換了：預設照 Artificial Analysis 排行榜的名次排，可以搜尋、照廠商與能力篩。

## 新東西

- **影片**（第六種生成）
  - 生成頁多一個「影片」分頁：寫提示詞，可以放首幀與尾幀（從電腦選、拖進來、或從作品牆挑），選模型（可搜尋、可篩「要首幀／要尾幀／要聲音」、可以整排比較），秒數、解析度、比例、聲音的選項跟著模型支援的範圍走
  - 送出前一定有一張確認單，寫明預估金額；超過 $1 的會特別標出來，並列出比較省的換法
  - 等待中看得到已經等了多久與供應商那邊的狀態；離開頁面再回來、甚至服務重新啟動，都會接著等——送出的當下就記下了供應商那邊的任務編號
  - 「不等了…」：供應商沒有取消這件事，所以按下去是**我們不再讓你等**；預設背景照樣把影片與實際費用收回來（設定頁可以改成不收，那筆帳會記「費用不明」）
  - 我們這邊最多等 20 分鐘（設定頁可改），超過時標「等太久」，留著「再去問一次」——不會重送、不會多收
  - 做好當場播放；作品牆有影片卡（封面、長度、有沒有聲音），燈箱裡可以播放、拖時間軸、調音量、全螢幕；圖片的燈箱多了「拿去做影片」，把那張圖放進影片表單的首幀
  - 模型頁多「影片」一類（每秒價格依解析度與聲音）；設定頁的〈預設模型〉多「影片」與三個影片設定；費用頁認得影片與「費用不明」
- **Gemini Omni 直連**（`gemini-omni-1.1-flash`，影片的第二個供應商）
  - 用你自己的 Google key 直接呼叫 Google，不經 OpenRouter；那個 key 的專案要開 **Gemini API 付費層**（Omni 沒有免費額度）
  - 影片模型清單多一個標「Google 直連」的；設了 Google 的 key 之後，OpenRouter 上的 `google/gemini-omni*` 與 `google/veo-*` 就不再重複列出（沒有 Google key 的人照樣看得到 OpenRouter 那一份）
  - **一定帶聲音**，沒有開關（不要聲音就在提示詞寫「no dialogue」「no music」）；3～10 秒，360p／720p（預設）／1080p，16:9 或 9:16；尾幀要跟首幀一起給
  - 預估：720p 有每秒價（約 $0.10）；其他解析度 Google 沒公布每秒用多少 token，送出前算不出，確認單寫「依實際用量」、MCP 要帶 `max_cost_usd`。做好之後照 Google 回報的費用與用量記實際費用
  - 這一版用「一直連著等到做好」的方式叫 Omni（Google 的背景查詢目前會回錯誤）。所以 Omni 這一支**服務重新啟動就接不回來**：等待中重啟服務，那一支會照實標成遺失（已送出、多半已收費），不會假裝還在等
  - 用真帳號打通：一支 3 秒 720p、有聲音，31 秒做好，實際 $0.31
- **MCP 工具 `generate_video`**（文字生影片，可帶首幀 `first_frame` 與尾幀 `last_frame`）
  - 等超過時間先回一張取件單，之後用 `get_job_result` 拿；服務重新啟動後取件單照樣能用
  - 單支預估上限預設 $1（設定頁可改或設成不限）：超過、或算不出金額的模型，不送出，回覆預估與怎麼放行（呼叫時帶 `max_cost_usd`）
- **OpenRouter 的圖片模型**
  - 生成與改圖都能用；名單與價格現查（每 24 小時更新），模型清單標出「經 OpenRouter・原廠是誰」
  - 圖片表單依模型支援的參數出選項（比例、解析度、品質、參考圖張數）；預估照 OpenRouter 名單的價格
  - 已經直連的原廠（OpenAI、Google 有設 key 時）不會重複列出 OpenRouter 那一份
  - MCP 的 `generate_image`、`edit_image` 可以直接用 OpenRouter 的模型 id（例如 `black-forest-labs/flux-3-image`）；`edit_image` 多了解析度與比例
- **ElevenLabs v4 與 v4 Turbo** 語音模型
- **Suno 兩首都收**
  - Suno 每次生歌、延長（含延長上傳的歌）、翻唱、加伴奏、加人聲都會回兩首；以前只下載第一首，現在兩首都下載、各是一件作品，作品詳情裡互相連得到；帳上記整次的費用，作品牆上兩首平分
  - MCP 的 `generate_music`（與 `edit_music` 會做出歌的動作）多回 `tracks`（每一首的檔案與 `audio_id`）與 `track_count`；頂層欄位照舊是第一首
  - 只想要第一首：`settings.json` 設 `"music": {"suno_all_tracks": false}`（或環境變數 `MUSIC__SUNO_ALL_TRACKS=false`），設定頁沒有這個開關
- **挑模型的清單：熱門排序與篩選**
  - 新對話（派工與聊天）、聊天裡換模型、生成頁的圖片／語音／音樂／轉錄表單與影片、模型頁，預設都照 [Artificial Analysis](https://artificialanalysis.ai) 排行榜的名次排：一條清單、不分廠商，名稱旁標「AA #n」
  - 挑模型的地方都是同一排篩選：搜尋、排序（熱門／廠商／價格）、只看可用、顯示全部（含還沒整理的模型）、廠商（可多選，照原廠算：經 OpenRouter 的 `openai/…` 跟直連的 OpenAI 算同一家）、能力（聊天與派工：看圖、收 PDF、會用工具；圖片：改圖、多張參考圖；影片：要首幀、要尾幀、要聲音）。模型頁保留自己的篩選，排序多一個「熱門（AA 名次）」並設成預設
  - 名次是手工抓的快照（2026-10-06），不會自己更新；沒上榜的排在後面
  - MCP 的 `list_available_models` 每一列多 `rank`（在 Artificial Analysis 榜上最好的名次，沒上榜就沒有這一欄）

## 修正與調整

- 模型目錄對帳：幾個即將關閉的模型標上關閉日期（模型頁會提醒），已關閉的標成下架；ElevenLabs 價格改成現價；`gpt-image-1-mini` 補上定價
- ElevenLabs 音樂的預設模型從已棄用的 v1 換成 v2.5（同價）
- 聊天裡提議配音時，預設不再指定 ElevenLabs（你在設定頁設了才用）
- Suno 的八個動作改走 kie.ai 的新端點：生歌、延長、翻唱、加伴奏、加人聲、寫歌詞、轉 WAV、做音樂影片（用真的 key 逐一打過；用起來沒有差別）。「延長上傳的歌」與分離人聲還走舊端點。每次扣的點數寫進了模型目錄：生歌／延長／翻唱／加伴奏／加人聲 12 點（一次兩首）、歌詞 0.4、轉 WAV 0.4、音樂影片 2；等待上限與連線逾時分開設定
- Claude 的思考參數：Claude 4.7 起的模型改送 adaptive thinking 加 `output_config.effort`（原本送思考長度預算會被 Anthropic 拒絕），也不再送 `temperature`／`top_p`；4.6 同樣的送法，但 xhigh 降成 high；4.7 起沒給回覆長度上限時預設 16000 token。Fable 5.1、Opus 5.5、Sonnet 5.5 不收「強制選工具」，改成讓模型自己決定（auto）並記一則警告。經 OpenRouter 的 Claude 改送 OpenRouter 統一的 `reasoning` 參數。**這一條沒有用真的帳號驗過**（照 Anthropic 文件與單元測試）
- 作品詳情（燈箱）不再顯示內部編號：圖片與音檔的「ID」那一列拿掉了
- kie.ai 回「請稍後再試」這類的失敗，現在歸成生成失敗，不再顯示成你的輸入有誤
- 給 Claude Desktop 的擴充（`omniapi-mcp.dxt`）多了選填的 OpenRouter key 欄位，填了就能用影片與 OpenRouter 的圖片模型
- 模型目錄載入時會檢查格式，有問題記在紀錄裡、服務照樣起得來

## 下載

| 檔案 | 用途 |
|---|---|
| `OmniAPI_1.4.0_x64-setup.exe` | **桌面版安裝包**。下載後執行；已經裝了舊版就直接覆蓋安裝 |
| `omniapi-v1.4.0.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |

**安裝包沒有程式碼簽章**，第一次執行時 Windows 可能會顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。想確認檔案沒被動過，用 `Get-FileHash OmniAPI_1.4.0_x64-setup.exe` 對 `SHA256SUMS.txt`。

## 升級

- **桌面版**：直接執行新的安裝包覆蓋安裝。安裝程式會先請正在跑的服務收尾；設定、key、資料庫與作品都不會動。裝完從開始功能表或系統匣重新打開
- **zip**：換上新版後在 `mcp/` 執行一次 `uv sync`，再重啟服務（`uv run omni stop` 再 `uv run omni serve`）
- 資料庫會在第一次啟動時自動升級（加上影片需要的欄位），舊的紀錄不變
- 已經開著的 Claude Code 要重新連線一次 MCP，才看得到 `generate_video`
- 想用影片與新的圖片模型，要在設定頁設好 OpenRouter 的 key（已經有就不用做什麼）

## 測過什麼、沒測過什麼

測過（都在一台 Windows 11 上）：

- 全部單元測試；安裝驗證腳本（從零安裝後走一遍，這一版加上：OpenRouter 的圖片名單與預估、生一張圖；影片名單與預估、生一支測試用的影片、上作品牆、可以拖時間軸）；聊天、生成、作品、設定、OpenRouter 圖片、影片的端到端測試，都在不連外的測試環境
- 影片的端到端包括：生到一半把服務強制結束再起來，影片照樣收回來；「不等了」之後背景收回來；等太久之後「再去問一次」不重送；經真的 MCP 連線拿取件單、取件單撐過服務重啟、超過上限被擋下、帶 `max_cost_usd` 放行；用前一版格式的資料庫升級，舊資料不變
- 影片畫面的 28 種狀態（表單、確認單、等待票、播放、作品牆、燈箱、模型頁、設定頁）在不連外的測試環境逐一做出來檢查，寬版與手機寬度
- 用真的 key 實際生過：OpenRouter 的圖片（生一張、拿它改圖一次）、影片（兩支 1 秒的短片，其中一支在等待中把服務強制結束、重新起來後自己接回來、收到檔案與費用）、Gemini Omni 直連（一支 3 秒 720p 有聲，實際 $0.31）、Suno 換到新端點的八個動作（各打一次）
- 這一版第一次用真帳號打通：Google 的 Lyria 音樂（一首 30 秒的 clip，$0.04）與 Gemini 生圖（1K 一張約 $0.067）
- 桌面版安裝包：在暫存資料夾安裝、`PATH` 裡沒有 Python、uv、Node 時第一次啟動、端到端、覆蓋安裝（服務正在跑的情況下）、解除安裝；安裝測試用的是另一個名字的測試版安裝包（跟正式版的程式識別、安裝位置、埠、資料夾都分開，才能在已經裝了正式版的電腦上測）
- zip 版：解壓到暫存資料夾、`uv sync`、不連外的測試環境跑安裝驗證與端到端

**沒測過**：

- 一份早一天的 1.4.0 候選安裝包在真的環境裡從 1.3.0 覆蓋安裝過（資料與設定都在）；**正式安裝包本身**只在獨立的測試版上跑過安裝、覆蓋、解除安裝，沒有在真的環境裝過——發布後第一個裝的人就是作者自己
- 沒有用真的 key 從生成頁的畫面走完一支影片的完整流程（服務那一段用真的 key 驗過，畫面是在測試環境驗的）；沒有從 Claude Code 用真的 key 叫過 `generate_video`
- 影片生成途中失敗時供應商收不收錢沒有實測（帳上會記「費用不明」）；額度不足、下載失敗這兩種錯誤只用模擬的回應看過
- 真的手機與觸控、全螢幕播放、把檔案拖進表單（跟點選上傳是同一段程式）沒有實際試

- 沒有在另一台乾淨的電腦上實機安裝過

## 已知限制

- **影片沒有真的取消**：供應商不提供取消，送出後錢就會花掉；「不等了」只是不再讓你等
- **按 token 計價的影片模型（Seedance 系列）送出前算不出金額**：確認單會寫「依實際用量」；MCP 要帶 `max_cost_usd` 才會送
- **OpenRouter 實際扣的錢有時比名單低**（實測 Wan 3.0 一支名單 $0.25、實扣 $0.2125；FLUX 3 改圖名單 $0.041、實扣 $0.0205，原因不明）。預估照名單、一律寫「約」，帳上記實際扣的
- Gemini Omni 直連等待中重啟服務，那一支會遺失（見上面〈新東西〉）；Sora 已關閉，Veo 3.1 Lite 經 OpenRouter 在下架日（2026-10-22）之前還能選（設了 Google key 時不列 OpenRouter 的 Veo）
- 影片的延伸、編輯、對嘴、放大，以及用多張參考圖生影片，這一版都沒有
- 只輸出向量圖（SVG）的 Recraft 模型這一版還不能用
- Suno 的「延長上傳的歌」與分離人聲還走舊端點
- 只在 Windows 11 上測試過；桌面版只有 Windows 的安裝包；服務只綁這台電腦、沒有登入機制，不要把 7788 埠開放到網路上
- 生成、轉錄、聊天會用你自己的 API key 呼叫供應商並產生費用；預估費用是估算，實際以供應商帳單為準
