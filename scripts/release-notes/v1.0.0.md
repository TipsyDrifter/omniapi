# OmniAPI v1.0.0

OmniAPI 從「一台 MCP 伺服器」變成「外部模型的派工中心」：一個常駐服務，三個入口——瀏覽器、Claude Code（MCP）、終端機——共用同一顆資料庫。

## 新東西

- **常駐服務 `omni serve`**：綁在 `127.0.0.1:7788`，同時提供 MCP、REST／WebSocket 與網頁介面；可以設定登入 Windows 時自動啟動
- **派工**：把任務交給 headless agent（Claude Code、Codex CLI、Gemini CLI，依模型自動選），可以追問、可以中止。Claude 模型預設走 Claude Code 的訂閱登入
- **看板**：正在跑的 agent 以票券顯示、即時活動流、歷史紀錄、兩本費用帳
- **聊天**：跟任何文字模型多輪對話，逐字顯示，每一則都能換模型，可匯出 markdown
- **終端機指令 `omni`**：`serve`／`status`／`stop`／`autostart`、`run`／`runs`／`run-log`、`chat`、`mcp-config`
- **MCP 工具 19 個**：新增 `run_agent`、`get_run`、`list_runs`、`cancel_run`、`chat`；音樂工具由 13 個收斂成 5 個
- **模型名單即時更新**：啟動時向各家查詢在線模型；新增 Anthropic、Google Gemini、OpenRouter；等級別名 `cheap`／`standard`／`strong`
- **離線沙盒**：`OMNIAPI_DEV=1 OMNIAPI_OFFLINE=1` 可以不花錢試用介面

## 下載

| 檔案 | 用途 |
|---|---|
| `omniapi-v1.0.0.zip` | 完整版（含已打包好的網頁介面）。解壓後在 `mcp/` 執行 `uv sync`，再 `uv run omni serve` |
| `omniapi-mcp.dxt` | Claude Desktop 擴充。獨立的 stdio 版 MCP server，沒有看板 |
| `omniapi-skill.zip` | 給 Claude 讀的 skill，放進 `~/.claude/skills/` 或上傳到 claude.ai |

安裝與設定見 README，操作方式見 USER_GUIDE。

## 注意

- 只在 Windows 11 上測試過
- 派工和聊天會用你自己的 API key 呼叫供應商，會產生費用
- 服務沒有登入機制，只綁本機；不要把 7788 埠開放到網路上
- 圖片、語音、音樂、轉錄目前只能透過 MCP 工具使用，網頁介面還沒有入口；還不支援影片

## 從 v0.4.x 升級

- MCP 設定從 stdio 改成 HTTP：在 `mcp/` 執行 `uv run omni mcp-config --apply`
- 音樂工具改名並合併，舊的 13 個工具名稱不再存在，改用 `generate_music`、`edit_music(action)`、`music_lyrics(action)`、`music_utility(action)`、`compose_music(action)`
- Gemini 改用 AI Studio 的 API key（`PROVIDERS__GEMINI__API_KEY`）
- DeepSeek 便宜模型的正式名稱是 `deepseek-flash`

---

**English summary.** OmniAPI 1.0 turns the MCP server into a local dispatch center: one daemon (`omni serve`, `127.0.0.1:7788`) with a web GUI (live board of agent runs, dispatch form with follow-ups and cancel, streaming multi-model chat, cost ledgers), an MCP endpoint with 19 tools (adds `run_agent` / `get_run` / `list_runs` / `cancel_run` / `chat`; music tools consolidated from 13 to 5), and the `omni` CLI. Agent runs go through the vendor's own headless harness (Claude Code, Codex CLI, Gemini CLI). Model rosters are discovered live; Anthropic, Gemini and OpenRouter join as text providers. An offline sandbox mode lets you try the UI without spending anything. Tested on Windows 11 only.
